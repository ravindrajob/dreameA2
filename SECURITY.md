# Security & Privacy Policy

## 🔒 Privacy & Data Protection Notice

This community package is designed with a strict **Privacy-First** architecture:
- **Zero Real Hardware Identifiers:** No device serial numbers, MAC addresses, cloud device IDs (`did`), or private access tokens are bundled or distributed.
- **100% Synthetic Geometry:** The included 3D point cloud (`demo_garden.pcd`) is procedurally generated using arbitrary mathematical formulas (undulating 20m × 15m grid with virtual tree geometries). It contains zero LiDAR survey data from any real physical property.
- **Local Network Isolation:** By default, Docker bindings listen on `127.0.0.1:8000` to prevent accidental exposure to the public internet.

## 🚨 Reporting a Vulnerability or Data Leak

If you discover any security issue, accidental inclusion of private identifiers, or credential leak, please report it confidentially via GitHub Security Advisories or open an issue with the `security` label.

All verified reports will be addressed and patched promptly.
