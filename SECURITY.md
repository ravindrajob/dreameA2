# Security & Privacy Policy

## Privacy & Data Protection

This repository follows a strict no-PII boundary for robotic mower geometry and Home Assistant credentials:

- **No Hardware Identifiers:** No device serial numbers, MAC addresses, cloud device IDs (`did`), or private access tokens are committed.
- **100% Synthetic Demo Geometry:** `web/assets/demo_garden.pcd` is procedurally generated by `scripts/generate_synthetic_pcd.py` (mathematical 20m x 15m terrain + virtual trees). No real property LiDAR survey is included.
- **Fail-Closed Command Gate:** `POST /api/action` refuses live commands (`HTTP 503`) if `HA_TOKEN` is configured without `API_AUTH_TOKEN`, and verifies tokens using `hmac.compare_digest`.
- **Loopback-First Networking:** Standalone Python binds to `127.0.0.1:8000` by default; Docker sets `HOST=0.0.0.0` inside the container while keeping host publication on `127.0.0.1:8000:8000`.
- **Offline Frontend:** Three.js `0.160.0` ES modules are vendorized locally under `web/vendor/` (zero external CDN calls).
